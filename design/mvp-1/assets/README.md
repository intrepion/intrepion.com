# Asset provenance

`google-g.png` is Google's official sign-in mark, downloaded unchanged on 2026-10-20 from [the Google Identity branding page's icon](https://developers.google.com/static/identity/images/g-logo.png). It is embedded into generated mockup HTML so local review makes no external requests.

See [Google's sign-in branding guidance](https://developers.google.com/identity/branding-guidelines). The static mockup uses a system-font approximation for the button label; production should use Google's rendered or pre-approved button rather than treating this design code as a compliant authentication widget. This asset is Google's brand mark, not a new project-owned logo.
